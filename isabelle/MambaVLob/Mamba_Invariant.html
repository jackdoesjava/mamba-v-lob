Theory Mamba_Invariant

theory Mamba_Invariant
  imports Complex_Main
begin

section ‹A machine-checked forward invariant for the selective SSM state›

text ‹
  This theory machine-checks the invariant argument of @{file ‹../docs/02-invariant.md›} and
  the LayerNorm bounds of @{file ‹../docs/03-certificate.md›}: the hidden state of a Mamba
  block with exact zero-order-hold discretisation never leaves the box ‹[-M, M]› with
  ‹M = sup |B u| / |A|›, at any sequence length, with no lower bound on the timescale.

  The five statements listed in the project brief are covered as follows.

    ▪ The weighted-average lemma           → @{text convex_combination_bound}
    ▪ ‹Abar = exp(dt * A) ∈ (0, 1)›        → @{text Abar_in_unit_interval}
    ▪ The zero-order-hold identity          → @{text zoh_identity}
    ▪ The induction over ‹t›                → @{text convex_recurrence_invariant},
                                              headline: @{text mamba_cell_state_bounded}
    ▪ LayerNorm and fused bounds, general d → @{text layernorm_bound},
                                              @{text fused_layernorm_linear_bound},
                                              @{text fused_layernorm_linear_attained}

  Everything is stated per coordinate: ‹A› is diagonal, so one cell is one scalar
  recurrence, and the block is 2048 independent copies of it. All statements are over the
  reals; floating point is out of scope here and remains the separate work item the brief
  lists as a bonus.
›

section ‹1. The weighted-average lemma›

text ‹
  A convex combination of two numbers in ‹[-M, M]› stays in ‹[-M, M]›. This is the whole
  mechanism: the coffee can never get hotter than the room. Stated on the closed interval
  ‹a ∈ [0, 1]› deliberately ― ‹the open interval is what the exact model produces, but the
  closed one is what the induction needs, and it additionally covers the two degenerate
  limits: ‹a = 1› (the update keeps the state; this is also where a float32 softplus
  underflow ‹delta = 0› lands) and ‹a = 0› (the state is flushed to the target).›
›

lemma convex_combination_bound:
  fixes a h c M :: real
  assumes "0 ≤ a" and "a ≤ 1" and "¦h¦ ≤ M" and "¦c¦ ≤ M"
  shows "¦a * h + (1 - a) * c¦ ≤ M"
proof -
  have "¦a * h + (1 - a) * c¦ ≤ a * ¦h¦ + (1 - a) * ¦c¦"
    using assms by (simp add: abs_mult abs_triangle_ineq[THEN order_trans] add_mono)
  also have "… ≤ a * M + (1 - a) * M"
    using assms by (intro add_mono mult_left_mono) auto
  also have "… = M"
    by (simp add: algebra_simps)
  finally show ?thesis .
qed

section ‹2. The discretised transition lies in the unit interval›

text ‹
  ‹Abar = exp(dt * A)› is a genuine convex weight for every timescale the selectivity
  mechanism can emit: strictly inside ‹(0, 1)› for ‹dt > 0›, and still inside ‹(0, 1]›
  when ‹dt› is only nonneg ― ‹the closed variant is the robustness margin for ‹dt = 0›.›
›

lemma Abar_in_unit_interval:
  fixes dt A :: real
  assumes "0 < dt" and "A < 0"
  shows "0 < exp (dt * A)" and "exp (dt * A) < 1"
proof -
  show "0 < exp (dt * A)" by simp
  have "dt * A < 0" using assms by (simp add: mult_pos_neg)
  then show "exp (dt * A) < 1" using exp_less_one_iff by simp
qed

lemma Abar_in_unit_interval_closed:
  fixes dt A :: real
  assumes "0 ≤ dt" and "A < 0"
  shows "0 < exp (dt * A)" and "exp (dt * A) ≤ 1"
proof -
  show "0 < exp (dt * A)" by simp
  have "dt * A ≤ 0" using assms by (simp add: mult_nonneg_nonpos)
  then show "exp (dt * A) ≤ 1" by simp
qed

section ‹3. The zero-order-hold identity and the convex form›

text ‹
  Proposition 1 of @{file ‹../docs/02-invariant.md›}: for ‹A < 0› the exact discretisation
  puts ‹1 - Abar› in the input gain, so the update is a weighted average. The Euler
  surrogate ‹Bbar ≈ dt * B› does not satisfy this identity, which is why the invariant
  belongs to the exact discretisation only.
›

lemma zoh_identity:
  fixes dt A B :: real
  assumes "A < 0"
  shows "(exp (dt * A) - 1) / A * B = (1 - exp (dt * A)) * B / ¦A¦"
proof -
  have "¦A¦ = - A" using assms by simp
  then show ?thesis using assms by (simp add: field_simps)
qed

lemma update_is_convex_combination:
  fixes dt A B u h :: real
  assumes "A < 0"
  defines "Abar ≡ exp (dt * A)" and "c ≡ B * u / ¦A¦"
  shows "Abar * h + (exp (dt * A) - 1) / A * B * u = Abar * h + (1 - Abar) * c"
  using assms by (simp add: field_simps)

text ‹
  The name "exact" is itself a theorem: the discrete step is the flow of the leaky
  integrator ‹h' = A h + b› (with ‹b = B u› held constant over the tick). The candidate
  ‹s ↦ exp(s A) h0 + (exp(s A) - 1)/A ⋅ b› starts at ‹h0› and satisfies the ODE, so the
  recurrence below is Newton's law of cooling sampled at the ticks, not an approximation
  of it. (Uniqueness of the flow is classical Picard--LindelÃ¶f and is not needed: the
  discrete recurrence is the verified object, and this lemma only certifies its pedigree.)
›

lemma zoh_is_exact_flow:
  fixes A b h0 s :: real
  assumes "A ≠ 0"
  shows "((λs. exp (s * A) * h0 + (exp (s * A) - 1) / A * b) has_field_derivative
          A * (exp (s * A) * h0 + (exp (s * A) - 1) / A * b) + b) (at s)"
    and "exp (0 * A) * h0 + (exp (0 * A) - 1) / A * b = h0"
proof -
  have "((λs. exp (s * A) * h0 + (exp (s * A) - 1) / A * b) has_field_derivative
         exp (s * A) * A * h0 + exp (s * A) * A / A * b) (at s)"
    by (auto intro!: derivative_eq_intros)
  moreover have "exp (s * A) * A * h0 + exp (s * A) * A / A * b
      = A * (exp (s * A) * h0 + (exp (s * A) - 1) / A * b) + b"
    using assms by (simp add: field_simps)
  ultimately show "((λs. exp (s * A) * h0 + (exp (s * A) - 1) / A * b) has_field_derivative
          A * (exp (s * A) * h0 + (exp (s * A) - 1) / A * b) + b) (at s)"
    by simp
  show "exp (0 * A) * h0 + (exp (0 * A) - 1) / A * b = h0"
    by simp
qed

section ‹4. The induction over time›

text ‹
  One step applied ‹t› times. The index convention shifts the paper's ‹h⇩-⇩1 = 0› to
  ‹h 0 = 0›: ‹h t› is the state after ‹t› ticks, and the coefficients consumed at tick
  ‹t+1› carry index ‹t›. The general form allows any initial state and yields
  ‹max ¦h 0¦ M›, so a deployment that carries state across windows stays certified: once
  inside the box, forever inside the box.
›

lemma convex_recurrence_bounded:
  fixes a c h :: "nat ⇒ real" and M :: real
  assumes step: "⋀t. h (Suc t) = a t * h t + (1 - a t) * c t"
    and weight_lo: "⋀t. 0 ≤ a t" and weight_hi: "⋀t. a t ≤ 1"
    and target: "⋀t. ¦c t¦ ≤ M"
  shows "¦h t¦ ≤ max ¦h 0¦ M"
proof (induction t)
  case 0
  then show ?case by simp
next
  case (Suc t)
  have "¦c t¦ ≤ max ¦h 0¦ M" using target[of t] by simp
  then have "¦a t * h t + (1 - a t) * c t¦ ≤ max ¦h 0¦ M"
    using Suc.IH weight_lo[of t] weight_hi[of t] by (intro convex_combination_bound)
  then show ?case by (simp add: step)
qed

corollary convex_recurrence_invariant:
  fixes a c h :: "nat ⇒ real" and M :: real
  assumes "h 0 = 0"
    and "⋀t. h (Suc t) = a t * h t + (1 - a t) * c t"
    and "⋀t. 0 ≤ a t" and "⋀t. a t ≤ 1"
    and "⋀t. ¦c t¦ ≤ M"
  shows "¦h t¦ ≤ M"
proof -
  have "0 ≤ M" using assms(5)[of 0] by simp
  moreover have "¦h t¦ ≤ max ¦h 0¦ M"
    using assms(2-5) by (rule convex_recurrence_bounded)
  ultimately show ?thesis using assms(1) by simp
qed

text ‹
  The headline theorem, assembled from the pieces. The hypotheses are exactly what the
  architecture supplies: ‹A < 0› from the parametrisation (Section 6), ‹dt > 0› from
  either timescale arm (Section 6), and ‹¦B u¦ ≤ K› from the certified boxes whose
  LayerNorm root is Section 5. The recurrence hypothesis is the exact zero-order hold as
  written, before any rearrangement. The conclusion holds for every ‹t› ― ‹the bound
  ‹K / ¦A¦› mentions no sequence length, no timescale floor, and no unrolling.›
›

theorem mamba_cell_state_bounded:
  fixes A K :: real and dt B u h :: "nat ⇒ real"
  assumes A_neg: "A < 0"
    and dt_pos: "⋀t. 0 < dt t"
    and drive: "⋀t. ¦B t * u t¦ ≤ K"
    and init: "h 0 = 0"
    and step: "⋀t. h (Suc t) =
                 exp (dt t * A) * h t + (exp (dt t * A) - 1) / A * B t * u t"
  shows "¦h t¦ ≤ K / ¦A¦"
proof -
  define a where "a ≡ λt. exp (dt t * A)"
  define c where "c ≡ λt. B t * u t / ¦A¦"
  have conv_step: "h (Suc t) = a t * h t + (1 - a t) * c t" for t
    using step[of t] update_is_convex_combination[OF A_neg, of "dt t" "h t" "B t" "u t"]
    by (simp add: a_def c_def)
  have a_lo: "0 ≤ a t" for t
    unfolding a_def by simp
  have a_hi: "a t ≤ 1" for t
    unfolding a_def using Abar_in_unit_interval[OF dt_pos A_neg] by (simp add: less_imp_le)
  have c_bound: "¦c t¦ ≤ K / ¦A¦" for t
  proof -
    have "¦c t¦ = ¦B t * u t¦ / ¦A¦"
      unfolding c_def by simp
    also have "… ≤ K / ¦A¦"
      using drive[of t] by (intro divide_right_mono) auto
    finally show ?thesis .
  qed
  show ?thesis
    by (rule convex_recurrence_invariant[of h a c "K / ¦A¦"])
       (use init conv_step a_lo a_hi c_bound in auto)
qed

section ‹5. The LayerNorm bounds, at the model's width and every other›

text ‹
  Z3 proves these at ‹d ≤ 5› and times out beyond; the model has ‹d = 64›. Here they are
  for every finite width, over an arbitrary finite index set. Complex_Main carries no
  Cauchy--Schwarz for finite sums, so it is proved first, by the discriminant argument.
›

lemma cauchy_schwarz_sum:
  fixes f g :: "'a ⇒ real" and I :: "'a set"
  shows "(∑i∈I. f i * g i)⇧2 ≤ (∑i∈I. (f i)⇧2) * (∑i∈I. (g i)⇧2)"
proof (cases "finite I ∧ (∑i∈I. (g i)⇧2) ≠ 0")
  case False
  then show ?thesis
  proof (cases "finite I")
    case True
    with False have g0: "(∑i∈I. (g i)⇧2) = 0" by blast
    then have "⋀i. i ∈ I ⟹ g i = 0"
      using True by (simp add: sum_nonneg_eq_0_iff)
    then have "(∑i∈I. f i * g i) = 0" by simp
    then show ?thesis using g0 by simp
  next
    case False
    then show ?thesis by simp
  qed
next
  case True
  then have fin: "finite I" and gnz: "(∑i∈I. (g i)⇧2) ≠ 0" by auto
  define Sg where "Sg = (∑i∈I. (g i)⇧2)"
  define t where "t = (∑i∈I. f i * g i) / Sg"
  have Sg_pos: "0 < Sg"
    unfolding Sg_def using gnz sum_nonneg[of I "λi. (g i)⇧2"]
    by (auto simp: less_le)
  have "0 ≤ (∑i∈I. (f i - t * g i)⇧2)"
    by (simp add: sum_nonneg)
  also have "(∑i∈I. (f i - t * g i)⇧2)
      = (∑i∈I. (f i)⇧2) - 2 * t * (∑i∈I. f i * g i) + t⇧2 * Sg"
    unfolding Sg_def
    by (simp add: power2_diff sum.distrib sum_subtractf sum_distrib_left
                  algebra_simps)
  finally have "0 ≤ (∑i∈I. (f i)⇧2) - (∑i∈I. f i * g i)⇧2 / Sg"
    using Sg_pos by (simp add: t_def power2_eq_square field_simps)
  then have "(∑i∈I. f i * g i)⇧2 / Sg ≤ (∑i∈I. (f i)⇧2)" by simp
  then show ?thesis
    using Sg_pos unfolding Sg_def by (simp add: divide_le_eq)
qed

text ‹
  The coordinate bound of @{file ‹../docs/03-certificate.md›}: on the LayerNorm constraint
  set (zero sum, energy at most ‹d›) no coordinate exceeds ‹sqrt (d - 1)›. To push one
  coordinate high, the other ‹d - 1› must cancel it, and the cancellation spends energy.
  The statement degenerates gracefully at ‹d = 1›: the constraints force ‹z = 0›.
›

lemma layernorm_coordinate_bound_sq:
  fixes z :: "'a ⇒ real" and I :: "'a set" and i :: 'a
  assumes fin: "finite I" and mem: "i ∈ I"
    and zsum: "(∑j∈I. z j) = 0"
    and znorm: "(∑j∈I. (z j)⇧2) ≤ real (card I)"
  shows "(z i)⇧2 ≤ real (card I) - 1"
proof -
  define J where "J = I - {i}"
  define D where "D = real (card I)"
  have card_pos: "0 < card I"
    using fin mem by (auto simp: card_gt_0_iff)
  have D_ge1: "1 ≤ D"
    unfolding D_def using card_pos by simp
  have "card J = card I - 1"
    unfolding J_def using mem by (simp add: card_Diff_singleton)
  then have cardJ: "real (card J) = D - 1"
    unfolding D_def using card_pos by (simp add: Suc_leI)
  have sumJ: "(∑j∈J. z j) = - z i"
    unfolding J_def using fin mem zsum by (simp add: sum_diff1)
  have sqJ: "(∑j∈J. (z j)⇧2) = (∑j∈I. (z j)⇧2) - (z i)⇧2"
    unfolding J_def using fin mem by (simp add: sum_diff1)
  have "(z i)⇧2 = (∑j∈J. z j * 1)⇧2"
    using sumJ by simp
  also have "… ≤ (∑j∈J. (z j)⇧2) * (∑j∈J. (1::real)⇧2)"
    by (rule cauchy_schwarz_sum)
  also have "(∑j∈J. (1::real)⇧2) = real (card J)"
    by simp
  finally have cs: "(z i)⇧2 ≤ (∑j∈J. (z j)⇧2) * (D - 1)"
    by (simp add: cardJ)
  have EJ: "(∑j∈J. (z j)⇧2) ≤ D - (z i)⇧2"
    using sqJ znorm unfolding D_def by simp
  have key: "(z i)⇧2 ≤ (D - (z i)⇧2) * (D - 1)"
    using cs EJ D_ge1 mult_right_mono[OF EJ, of "D - 1"] by simp
  have expand: "(D - (z i)⇧2) * (D - 1) = D * D - D - (z i)⇧2 * D + (z i)⇧2"
    by (simp add: algebra_simps)
  from key have "0 ≤ D * D - D - (z i)⇧2 * D"
    unfolding expand by linarith
  also have "D * D - D - (z i)⇧2 * D = D * (D - 1 - (z i)⇧2)"
    by (simp add: algebra_simps)
  finally have "0 ≤ D - 1 - (z i)⇧2"
    using D_ge1 by (auto simp: zero_le_mult_iff)
  then show ?thesis
    unfolding D_def by linarith
qed

corollary layernorm_coordinate_bound:
  fixes z :: "'a ⇒ real" and I :: "'a set" and i :: 'a
  assumes "finite I" and "i ∈ I"
    and "(∑j∈I. z j) = 0"
    and "(∑j∈I. (z j)⇧2) ≤ real (card I)"
  shows "¦z i¦ ≤ sqrt (real (card I) - 1)"
proof -
  have "(z i)⇧2 ≤ real (card I) - 1"
    by (rule layernorm_coordinate_bound_sq[OF assms])
  then have "sqrt ((z i)⇧2) ≤ sqrt (real (card I) - 1)"
    by (rule real_sqrt_le_mono)
  then show ?thesis
    by simp
qed

text ‹
  The constraint set is not an assumption on the data: the normalisation itself lands in
  it, for every input ‹x ∈ ℝ⇧d› and every ‹eps > 0›. This is the full Proposition of
  @{file ‹../docs/03-certificate.md›}, ‹¦LN(x)⇩i - beta⇩i¦ ≤ ¦gamma⇩i¦ sqrt (d - 1)›, with the
  biased variance PyTorch uses. The architecture manufactures the invariant's premise.
›

theorem layernorm_bound:
  fixes x gamma beta :: "'a ⇒ real" and I :: "'a set" and i :: 'a and eps :: real
  assumes fin: "finite I" and mem: "i ∈ I" and eps_pos: "0 < eps"
  defines "d ≡ real (card I)"
    and "mu ≡ (∑j∈I. x j) / real (card I)"
  defines "var ≡ (∑j∈I. (x j - mu)⇧2) / real (card I)"
  defines "z ≡ λj. (x j - mu) / sqrt (var + eps)"
  defines "LN ≡ λj. gamma j * z j + beta j"
  shows "¦LN i - beta i¦ ≤ ¦gamma i¦ * sqrt (d - 1)"
proof -
  have card_pos: "0 < card I"
    using fin mem by (auto simp: card_gt_0_iff)
  have d_pos: "0 < d"
    unfolding d_def using card_pos by simp
  have var_nonneg: "0 ≤ var"
    unfolding var_def by (simp add: sum_nonneg)
  have veps_pos: "0 < var + eps"
    using var_nonneg eps_pos by simp
  have centred_sum: "(∑j∈I. x j - mu) = 0"
    using d_pos unfolding mu_def d_def by (simp add: sum_subtractf)
  have zsum: "(∑j∈I. z j) = 0"
    unfolding z_def by (simp flip: sum_divide_distrib add: centred_sum)
  have centred_sq: "(∑j∈I. (x j - mu)⇧2) = d * var"
    using d_pos unfolding var_def d_def by simp
  have z_sq_pointwise: "(z j)⇧2 = (x j - mu)⇧2 / (var + eps)" for j
    unfolding z_def using veps_pos by (simp add: power_divide)
  have z_sq: "(∑j∈I. (z j)⇧2) = d * var / (var + eps)"
    by (simp add: z_sq_pointwise flip: sum_divide_distrib) (simp add: centred_sq)
  have "d * var / (var + eps) ≤ d"
    using d_pos var_nonneg eps_pos
    by (simp add: divide_le_eq mult_left_mono)
  with z_sq have znorm: "(∑j∈I. (z j)⇧2) ≤ real (card I)"
    unfolding d_def by simp
  have "¦z i¦ ≤ sqrt (real (card I) - 1)"
    by (rule layernorm_coordinate_bound[OF fin mem zsum znorm])
  then have "¦gamma i¦ * ¦z i¦ ≤ ¦gamma i¦ * sqrt (real (card I) - 1)"
    by (intro mult_left_mono) auto
  then show ?thesis
    unfolding LN_def d_def by (simp add: abs_mult)
qed

text ‹
  The fused LayerNorm-and-Linear bound: over the constraint set, ‹⟨v, z⟩› is bounded by
  ‹∥v - mean v∥⇩2 sqrt d› ― ‹the zero-sum constraint subtracts the mean of the weight row
  for free, an ‹l⇩2› quantity where boxing the LayerNorm first pays an ‹l⇩1› one. This is
  the 49x on the certified radius.› Soundness first, then attainment: the maximiser lies
  in the set and meets the bound with equality, so the fused bound cannot be improved.
›

lemma fused_layernorm_linear_bound:
  fixes v z :: "'a ⇒ real" and I :: "'a set"
  assumes fin: "finite I"
    and zsum: "(∑j∈I. z j) = 0"
    and znorm: "(∑j∈I. (z j)⇧2) ≤ real (card I)"
  defines "vbar ≡ (∑j∈I. v j) / real (card I)"
  shows "¦∑j∈I. v j * z j¦ ≤ sqrt (∑j∈I. (v j - vbar)⇧2) * sqrt (real (card I))"
proof -
  have "(∑j∈I. (v j - vbar) * z j) = (∑j∈I. v j * z j) - vbar * (∑j∈I. z j)"
    by (simp add: left_diff_distrib sum_subtractf flip: sum_distrib_left)
  then have shift: "(∑j∈I. v j * z j) = (∑j∈I. (v j - vbar) * z j)"
    by (simp add: zsum)
  have "(∑j∈I. (v j - vbar) * z j)⇧2 ≤ (∑j∈I. (v j - vbar)⇧2) * (∑j∈I. (z j)⇧2)"
    by (rule cauchy_schwarz_sum)
  also have "… ≤ (∑j∈I. (v j - vbar)⇧2) * real (card I)"
    using znorm by (intro mult_left_mono) (auto simp: sum_nonneg)
  finally have sq: "(∑j∈I. v j * z j)⇧2 ≤ (∑j∈I. (v j - vbar)⇧2) * real (card I)"
    using shift by simp
  have "¦∑j∈I. v j * z j¦ = sqrt ((∑j∈I. v j * z j)⇧2)"
    by simp
  also have "… ≤ sqrt ((∑j∈I. (v j - vbar)⇧2) * real (card I))"
    using sq by (rule real_sqrt_le_mono)
  also have "… = sqrt (∑j∈I. (v j - vbar)⇧2) * sqrt (real (card I))"
    by (simp add: real_sqrt_mult)
  finally show ?thesis .
qed

lemma fused_layernorm_linear_attained:
  fixes v :: "'a ⇒ real" and I :: "'a set"
  assumes fin: "finite I" and ne: "I ≠ {}"
  defines "vbar ≡ (∑j∈I. v j) / real (card I)"
  defines "N ≡ sqrt (∑j∈I. (v j - vbar)⇧2)"
  assumes N_pos: "0 < N"
  defines "zstar ≡ λj. sqrt (real (card I)) * (v j - vbar) / N"
  shows "(∑j∈I. zstar j) = 0"
    and "(∑j∈I. (zstar j)⇧2) = real (card I)"
    and "(∑j∈I. v j * zstar j) = N * sqrt (real (card I))"
proof -
  have card_pos: "0 < card I"
    using fin ne by (auto simp: card_gt_0_iff)
  have Nsq: "N⇧2 = (∑j∈I. (v j - vbar)⇧2)"
    unfolding N_def by (simp add: sum_nonneg)
  have sum_pos: "0 < (∑j∈I. (v j - vbar)⇧2)"
    using N_pos Nsq zero_less_power[of N 2] by simp
  have centred_sum: "(∑j∈I. v j - vbar) = 0"
    using card_pos unfolding vbar_def by (simp add: sum_subtractf)
  show "(∑j∈I. zstar j) = 0"
    unfolding zstar_def
    by (simp add: centred_sum flip: sum_divide_distrib sum_distrib_left)
  have "(∑j∈I. (zstar j)⇧2)
      = real (card I) * (∑j∈I. (v j - vbar)⇧2) / N⇧2"
    unfolding zstar_def
    by (simp add: power_divide power_mult_distrib sum_nonneg
             flip: sum_divide_distrib sum_distrib_left)
  then show "(∑j∈I. (zstar j)⇧2) = real (card I)"
    using N_pos Nsq sum_pos by simp
  have vdot: "(∑j∈I. v j * (v j - vbar)) = (∑j∈I. (v j - vbar)⇧2)"
  proof -
    have "v j * (v j - vbar) = (v j - vbar)⇧2 + vbar * (v j - vbar)" for j
      by (simp add: power2_eq_square algebra_simps)
    then have "(∑j∈I. v j * (v j - vbar))
        = (∑j∈I. (v j - vbar)⇧2) + vbar * (∑j∈I. v j - vbar)"
      by (simp add: sum.distrib flip: sum_distrib_left)
    then show ?thesis by (simp add: centred_sum)
  qed
  have pointwise: "v j * zstar j = sqrt (real (card I)) * (v j * (v j - vbar)) / N" for j
    unfolding zstar_def by (simp add: mult_ac)
  have "(∑j∈I. v j * zstar j) = sqrt (real (card I)) * (∑j∈I. v j * (v j - vbar)) / N"
    by (simp add: pointwise flip: sum_divide_distrib sum_distrib_left)
  also have "… = sqrt (real (card I)) * N⇧2 / N"
    by (simp add: vdot Nsq)
  also have "… = N * sqrt (real (card I))"
    using N_pos by (simp add: power2_eq_square)
  finally show "(∑j∈I. v j * zstar j) = N * sqrt (real (card I))" .
qed

section ‹7. The abstraction gap is a genuine gap›

text ‹
  The closed-form overcharge of @{file ‹../docs/02-invariant.md›},
  ‹gap = (1 - exp(-lam d_hi)) / (1 - exp(-lam d_lo))›, is at least ‹1› whenever the
  timescale box is nondegenerate: the geometric bound never beats the invariant, at any
  pole and any timescale range. (Its divergence as ‹d_lo → 0› is visible in the formula;
  the invariant does not mention ‹d_lo› at all.)
›

lemma abstraction_gap_ge_one:
  fixes lam d_lo d_hi :: real
  assumes lam_pos: "0 < lam" and lo_pos: "0 < d_lo" and le: "d_lo ≤ d_hi"
  shows "1 ≤ (1 - exp (- lam * d_hi)) / (1 - exp (- lam * d_lo))"
proof -
  have denom_pos: "0 < 1 - exp (- lam * d_lo)"
    using lam_pos lo_pos by simp
  have "exp (- lam * d_hi) ≤ exp (- lam * d_lo)"
    using lam_pos le by simp
  then have "1 - exp (- lam * d_lo) ≤ 1 - exp (- lam * d_hi)"
    by simp
  then show ?thesis
    using denom_pos by simp
qed
